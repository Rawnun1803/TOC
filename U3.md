# **Unit III – Context Free Grammar (CFG)**

## **1. Definition of Context Free Grammar (CFG)**

A **Context Free Grammar (CFG)** is a formal grammar used to generate Context Free Languages (CFLs).

- A CFG consists of production rules in which the left-hand side contains exactly one non-terminal.
- It is used to describe the syntax and structure of programming languages.
- Each production replaces a non-terminal with a string of terminals and/or non-terminals.

**Formal representation:**

\\[ G=(V,T,P,S) \\]

Where:

- \\(V\\) – Set of non-terminals.
- \\(T\\) – Set of terminals.
- \\(P\\) – Set of production rules.
- \\(S\\) – Start symbol.

**General production form:**

\\[ A\rightarrow\alpha \\]

Where \\(A\\) is a non-terminal and \\(\alpha\\) is any string of terminals and non-terminals.

**Example:**

\\[ S\rightarrow aSb\mid\epsilon \\]

Generates:

\\[ L=\\{a^nb^n\mid n\geq0\\} \\]

## **2. Leftmost Derivation and Rightmost Derivation**

Derivation is the process of generating a string from the start symbol by applying production rules.

**Example CFG:**

\\[ S\rightarrow AB \\]

\\[ A\rightarrow aA\mid a \\]

\\[ B\rightarrow bB\mid b \\]

**Leftmost Derivation (LMD)**

- The leftmost non-terminal is replaced first at every step.
- The process continues until only terminals remain.

Example:

\\[ S\Rightarrow AB \\]

\\[ \Rightarrow aAB \\]

\\[ \Rightarrow aaB \\]

\\[ \Rightarrow aab \\]

**Rightmost Derivation (RMD)**

- The rightmost non-terminal is replaced first at every step.
- The process continues until only terminals remain.

Example:

\\[ S\Rightarrow AB \\]

\\[ \Rightarrow AbB \\]

\\[ \Rightarrow Abb \\]

\\[ \Rightarrow a bb \\]

**Difference:**

| Leftmost Derivation                   | Rightmost Derivation                                                     |
| ------------------------------------- | ------------------------------------------------------------------------ |
| Replaces leftmost non-terminal first. | Replaces rightmost non-terminal first.                                   |
| Also called leftmost expansion.       | Also called rightmost expansion.                                         |
| Used in top-down parsing.             | Used in bottom-up parsing concepts through reverse rightmost derivation. |

## **3. Ambiguity in CFG**

A CFG is called **ambiguous** if at least one string in its language has more than one parse tree or more than one leftmost/rightmost derivation.

- Ambiguity occurs when a string can be interpreted in multiple ways.
- It creates confusion in determining the structure of an expression.
- A grammar is unambiguous if every generated string has exactly one parse tree.

**Example:**

\\[ E\rightarrow E+E\mid E\*E\mid id \\]

For the string:

\\[ id+id\*id \\]

Two interpretations are possible:

- \\((id+id)\*id\\)
- \\(id+(id\*id)\\)

## **4. Conversion of Left Regular Grammar (LRG) to Right Regular Grammar (RRG)**

A Left Regular Grammar has productions in which the non-terminal appears at the left end of the right-hand side.

**Common forms:**

\\[ A\rightarrow Ba\mid a\mid\epsilon \\]

A Right Regular Grammar has productions in which the non-terminal appears at the right end.

**Common forms:**

\\[ A\rightarrow aB\mid a\mid\epsilon \\]

**Conversion method:**

1. Construct a finite automaton equivalent to the given LRG.
2. Reverse the direction of all transitions.
3. Make the original final states the new initial states.
4. Make the original initial state the new final state.
5. Convert the resulting automaton into a right regular grammar.

**Key idea:** Reverse the language using an automaton and then obtain the equivalent RRG.

## **5. Conversion of Right Regular Grammar (RRG) to Left Regular Grammar (LRG)**

A Right Regular Grammar contains productions in which the non-terminal appears at the right end.

**Conversion method:**

1. Construct a finite automaton equivalent to the given RRG.
2. Reverse the direction of all transitions.
3. Make the original final states the new initial states.
4. Make the original initial state the new final state.
5. Convert the resulting automaton into a left regular grammar.

**Key idea:** Use the reverse automaton to obtain an equivalent LRG.

**Important:** If reversing creates multiple initial states, introduce a new initial state with ε-transitions to the required states. The resulting grammar may need ε-productions.

## **6. Simplification of CFG**

Simplification means removing unnecessary production rules and symbols without changing the language generated by the grammar, except where ε is intentionally excluded or preserved according to the required convention.

### **A. Removal of Null Productions**

A null production is a production that generates an empty string.

**Form:**

\\[ A\rightarrow\epsilon \\]

**Steps:**

1. Identify all nullable non-terminals.
2. A non-terminal is nullable if it directly or indirectly derives ε.
3. For each production containing nullable symbols, create alternatives by omitting those symbols.
4. Repeat for all nullable occurrences.
5. Remove the original null productions.
6. Preserve \\(S\rightarrow\epsilon\\) if ε belongs to the language, usually by introducing a new start symbol.

**Example:**

Given:

\\[ S\rightarrow AB \\]

\\[ A\rightarrow a\mid\epsilon \\]

\\[ B\rightarrow b \\]

Since A is nullable, add:

\\[ S\rightarrow AB\mid B \\]

Remove:

\\[ A\rightarrow\epsilon \\]

### **B. Removal of Unit Productions**

A unit production is a production in which one non-terminal produces another non-terminal.

**Form:**

\\[ A\rightarrow B \\]

**Steps:**

1. Identify all unit productions.
2. Find the productions of the non-terminal on the right-hand side.
3. Add those productions to the non-terminal on the left-hand side.
4. Repeat until all unit productions are eliminated.
5. Remove the original unit productions.

**Example:**

Given:

\\[ S\rightarrow A \\]

\\[ A\rightarrow a\mid b \\]

Replace \\(S\rightarrow A\\) with:

\\[ S\rightarrow a\mid b \\]

Remove \\(S\rightarrow A\\).

### **C. Removal of Useless Symbols**

A useless symbol is a symbol that does not contribute to generating any terminal string reachable from the start symbol.

There are two types:

- **Non-generating symbols:** Cannot derive a string containing only terminals.
- **Unreachable symbols:** Cannot be reached from the start symbol.

**Steps:**

1. Identify all generating non-terminals.
2. Remove non-generating symbols and their productions.
3. Start from the start symbol.
4. Find all reachable symbols.
5. Remove unreachable symbols and their productions.

**Example:**

\\[ S\rightarrow aA\mid b \\]

\\[ A\rightarrow a \\]

\\[ B\rightarrow c \\]

Here, B is unreachable from S, so remove B and its production.

## **7. Conversion to Chomsky Normal Form (CNF)**

A CFG is in **Chomsky Normal Form (CNF)** if every production is of the following forms:

\\[ A\rightarrow BC \\]

\\[ A\rightarrow a \\]

Where:

- A, B, C are non-terminals.
- a is a terminal.
- \\(S\rightarrow\epsilon\\) is allowed if ε belongs to the language, under the usual start-symbol exception.

**Conversion steps:**

1. Introduce a new start symbol if required.
2. Remove null productions.
3. Remove unit productions.
4. Remove useless symbols.
5. Replace terminals appearing with non-terminals in longer productions.
6. Break productions having more than two symbols on the right-hand side into binary productions.
7. Ensure every production follows CNF rules.

**Example:**

Given:

\\[ S\rightarrow aAB \\]

\\[ A\rightarrow b \\]

\\[ B\rightarrow c \\]

Introduce:

\\[ X\rightarrow a \\]

\\[ S\rightarrow XC \\]

\\[ C\rightarrow AB \\]

\\[ A\rightarrow b,\quad B\rightarrow c \\]

All productions now follow CNF form.

**Uses:**

- Used in the CYK parsing algorithm.
- Simplifies parsing and theoretical analysis of CFGs.

## **8. Conversion to Greibach Normal Form (GNF)**

A CFG is in **Greibach Normal Form (GNF)** if every production begins with a terminal followed by zero or more non-terminals.

**General form:**

\\[ A\rightarrow aA_1A_2\ldots A_n \\]

Where:

- a is a terminal.
- \\(A_1,A_2,\ldots,A_n\\) are non-terminals.
- \\(n\geq0\\).
- \\(S\rightarrow\epsilon\\) is allowed if ε belongs to the language, under the usual start-symbol exception.

**Conversion steps:**

1. Remove null productions.
2. Remove unit productions.
3. Remove useless symbols.
4. Arrange non-terminals in a suitable order.
5. Eliminate left recursion.
6. Replace productions beginning with non-terminals using their corresponding productions.
7. Continue until every production begins with a terminal.

**Example:**

Given:

\\[ S\rightarrow AB \\]

\\[ A\rightarrow a \\]

\\[ B\rightarrow b \\]

Substitute \\(A\rightarrow a\\) into S:

\\[ S\rightarrow aB \\]

\\[ A\rightarrow a \\]

\\[ B\rightarrow b \\]

All productions are now in GNF.

**Uses:**

- Every derivation step generates exactly one terminal.
- Useful in proving properties of context-free languages.

- Every regular language is context-free.
- Every context-free language is context-sensitive.

## **10. Context Free Language (CFL) and Its Properties**

A **Context Free Language (CFL)** is a language generated by a Context Free Grammar.

- It is generated using CFG production rules.
- It can be recognized by a Pushdown Automaton (PDA).
- It uses a stack to remember previously encountered symbols.
- It can represent nested structures such as balanced parentheses.
- It is more powerful than regular languages.

**Example:**

\\[ L=\\{a^nb^n\mid n\geq0\\} \\]

CFG:

\\[ S\rightarrow aSb\mid\epsilon \\]

**Properties:**

- Every regular language is a CFL.
- Not every CFL is regular.
- CFLs can be recognized by NPDAs.
- CFLs can be represented using parse trees.
- CFLs are closed under union, concatenation and Kleene star.
- CFLs are not closed under intersection and complement in general.

## **11. Pumping Lemma for CFL**

The Pumping Lemma is used to prove that certain languages are **not context-free**.

If L is a context-free language, then there exists a constant p such that every string \\(w\in L\\), with \\(|w|\geq p\\), can be divided into five parts:

\\[ w=uvxyz \\]

Such that:

1. \\(|vxy|\leq p\\)
2. \\(|vy|\geq1\\)
3. \\(uv^ixy^iz\in L\\), for every \\(i\geq0\\).

**Meaning:**

- u, v, x, y, z are parts of the string.
- v and y are the portions that are repeated.
- Both v and y are pumped the same number of times.
- At least one of v and y must be non-empty.

**Steps to prove a language is not CFL:**

1. Assume that the given language is context-free.
2. Let p be its pumping length.
3. Choose a suitable string \\(w\in L\\), where \\(|w|\geq p\\).
4. Divide w into \\(uvxyz\\), satisfying the pumping conditions.
5. Consider all possible valid divisions.
6. Choose a pumping value, usually \\(i=0\\) or \\(i=2\\).
7. Show that the pumped string does not belong to L.
8. This contradicts the Pumping Lemma; therefore, L is not context-free.

**Example of a non-CFL:**

\\[ L=\\{a^nb^nc^n\mid n\geq1\\} \\]

This language is not context-free because a single stack cannot independently keep track of three equal-sized groups in the required order.

**Important:** Pumping Lemma can prove that a language is not CFL, but it cannot prove that a language is CFL.

## **12. Closure Properties of CFL**

Closure properties describe whether applying an operation to context-free languages always produces another context-free language.

**Operations under which CFLs are closed:**

| Operation                          | Closed? |
| ---------------------------------- | ------- |
| Union                              | Yes     |
| Concatenation                      | Yes     |
| Kleene Star                        | Yes     |
| Reversal                           | Yes     |
| Homomorphism                       | Yes     |
| Inverse Homomorphism               | Yes     |
| Intersection with Regular Language | Yes     |

**Operations under which CFLs are not closed:**

| Operation                | Closed? |
| ------------------------ | ------- |
| Intersection of two CFLs | No      |
| Complement               | No      |
| Difference of two CFLs   | No      |

**Examples:**

- If \\(L_1\\) and \\(L_2\\) are CFLs, then \\(L_1\cup L_2\\) is also a CFL.
- If \\(L_1\\) and \\(L_2\\) are CFLs, their intersection is not necessarily a CFL.
- Complement of a CFL is not necessarily a CFL.
